# Warehouse Inventory & Expiry Management System (WIEMS)

Version: 1.0
Author: Copilot
Status: Draft

---

# 1. Executive Summary

## Problem Statement

The current inventory management process relies heavily on Google Sheets.

Current issues include:

- New inventory arrivals are not updated consistently.
- Expiry dates are not monitored proactively.
- Items are categorized inconsistently.
- Duplicate item records appear under different categories.
- Difficult item searching and tracking.
- No centralized inventory history.
- No automated notification for expiring items.
- Heavy dependence on employee memory.

Example:

SKU: GZ001

Sterile Gauze may appear under:

- First Aid
- Disposable

causing confusion, duplicate tracking, inaccurate stock reporting, and potential purchasing mistakes.

---

# 2. Business Objectives

The system should:

1. Create a Single Source of Truth for all inventory.
2. Prevent duplicate SKU creation.
3. Track inventory batches and expiry dates.
4. Automatically generate expiry alerts.
5. Provide fast item search capability.
6. Support both desktop and mobile devices.
7. Support barcode scanning where available.
8. Allow controlled category management.
9. Track inventory movements.
10. Reduce inventory loss due to expiry.

# 4. Core Modules

## Module 1: Item Master

Purpose:

Maintain a single master record for each product.

### Features

- SKU Management
- Product Registration
- Category Assignment
- Unit Cost Tracking
- Barcode Support

### Rules

One SKU = One Item

Example:

SKU: GZ001
Name: Sterile Gauze 10x10

Category:
First Aid

System prevents creation of:

SKU: GZ001
Category: Disposable

unless authorized adjustment is performed.

---

## Module 2: Category Management

### Purpose

Standardize inventory classification.

### Features

- Create Category
- Edit Category
- Disable Category

### Access

Only:

- Administrator
- Authorized Personnel

### Example Categories

- First Aid
- Disposable
- PPE
- Medical Devices
- Consumables
- Chemicals
- Office Supplies

---

## Module 3: Inventory Receiving

### Current Workflow

Receive Item
→ Verify Invoice
→ Record in Google Sheet
→ Store Inventory

### New Workflow

Create PO
→ Receive PO
→ Verify Quantity
→ Record Batch
→ Record Expiry Date
→ Store Inventory
→ System Updates Inventory

### Inputs

- PO Number
- Supplier
- SKU
- Quantity
- Unit Cost
- Batch Number
- MFG Date
- Expiry Date

---

## Module 4: Inventory Issue

Purpose:

Track stock leaving warehouse.

### Inputs

- SKU
- Quantity
- Requestor
- Department
- Remarks

### Outputs

Inventory reduced automatically.

---

## Module 5: Expiry Management

Critical module.

### Automatic Status

#### Healthy

Expiry > 90 days

#### Warning

Expiry <= 90 days

#### Critical

Expiry <= 30 days

#### Expired

Current Date > Expiry Date

---

### Dashboard Widgets

Show:

- Total Expired Items
- Expiring in 90 Days
- Expiring in 30 Days
- Inventory Value at Risk

---

### Notifications

System should send alerts:

- 90 days before expiry
- 60 days before expiry
- 30 days before expiry
- 7 days before expiry

Channels:

- Dashboard Notifications
- Email Notifications

Future:

- WhatsApp Integration
